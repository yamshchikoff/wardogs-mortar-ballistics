# Wardogs — баллистика миномёта L81

## Продукт — `mortar.html`

**Единственный продуктовый файл — `mortar.html`.** Это самодостаточная страница: вёрстка,
стили и скрипт внутри, без внешних зависимостей и без сети. Открывается прямо из файла
(или с GitHub Pages) и считает:

- **мил** для наводки — нисходящий (навесной) и восходящий (прямой);
- **азимут**;
- **время полёта** до цели;
- **превышение цели** — тремя способами: своим дальномером, вручную или **цепочкой через
  рекон** (дальномер до рекона + его координаты + дальномер с рекона до цели).

Есть переключатель цветовой схемы для дальтоников.

## Модель

Движение мины — с линейным и квадратичным сопротивлением, решается численно (RK4):

```
dv/dt = −g·ŷ − γ·v − β·|v|·v
```

| параметр | значение | смысл |
|---|---|---|
| v₀ | 261.0 м/с | начальная скорость |
| γ = k₁/m | 0.04238 1/с | вязкое (линейное) сопротивление |
| β = k₂/m | 0.00235 1/м | квадратичное сопротивление |
| g | 9.81 м/с² | гравитация |
| масса m | — | не определяется по траектории (входит только как k₁/m, k₂/m) |

Шкала прицела (отображение показания mil в угол возвышения):

```
θ(mil) = 33.54° + 0.058418°·mil        (≈ 6162 mil на полный круг)
```

Качество: дальности прицела — rms 0.81 м; времена полёта — в пределах ~2σ (σ=0.5 с);
полевые выстрелы — в пределах размера цели.

Подробности — в [`models.md`](models.md) (все модели и что отброшено) и
[`trajectory-model.json`](trajectory-model.json) (машиночитаемо).
